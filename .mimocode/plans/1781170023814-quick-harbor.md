# 刺客信条风格动作游戏 Demo — 简历技术亮点分析

## 项目概述

Unity 2022.3 LTS 第三人称动作游戏 Demo，使用 URP 渲染管线，集成了 VRM 角色模型、Cinemachine 相机、AI Navigation 寻路和 Unity Input System 输入系统。

---

## 简历技术亮点（每段约50字）

### 1. 泛型状态机框架
基于泛型 `State<T>` / `StateMachine<T>` 实现可复用的状态机框架，敌人 AI 拥有 Idle/Patrol/CombatMovement/Attack/Retreat/Dead/GettingHit 七种状态，状态切换逻辑清晰解耦。

### 2. 动画驱动的战斗系统
通过 `AttackData` ScriptableObject 配置攻击动画、判定框与生效时间窗口，实现前摇→判定→后摇三阶段战斗节奏，支持连击队列和反击演出机制。

### 3. 多判定点碰撞检测
战斗系统在角色骨骼（双手双脚）与武器上分别挂载碰撞体，根据 `AttackData` 动态启用对应判定点，实现不同攻击动作命中不同部位的精准打击。

### 4. AI 战斗行为树
敌人 AI 实现追击→环绕→攻击→后撤的战斗循环，环绕阶段通过四元数旋转实现围绕目标移动，配合 NavMeshAgent 寻路和随机决策，呈现有层次的敌方行为。

### 5. 索敌锁定与反击系统
玩家可锁定最近敌人进入环绕战斗模式，锁定时禁用自由相机轴、切换移动参考系为敌人方向；敌人前摇阶段可触发反击演出，双方向量对齐实现处决动画。

### 6. 动画控制器热替换
武器装备时通过 `RuntimeAnimatorController` 覆盖实现攻击动画热切换，不同武器类型可配置独立动画集，卸装时恢复原始控制器，无需重建 Animator。

### 7. UI 面板动态加载系统
基于 Resources 按需加载 UI 面板预制体，使用字典缓存已加载面板，面板名称常量统一管理，支持打开/关闭/查询状态，实现轻量级 UI 管理框架。

### 8. 数据持久化与背包系统
背包数据通过 `JsonUtility` 序列化为 JSON 存入 `PlayerPrefs`，支持物品增删、装备状态同步、武器类型动态匹配，事件驱动 UI 刷新保持数据一致性。

### 9. 速度缓存平滑系统
玩家跳跃时使用三帧速度缓存数组计算平均速度，避免动画驱动移动时的帧间抖动，通过 `fallMultiplier` 区分上升/下落阶段实现更真实的物理手感。

### 10. 敌方协同告警机制
敌人被攻击时通过 `Physics.OverlapBox` 检测范围内友方，触发邻近敌人进入战斗状态，实现"一人被攻击、周围增援"的协同作战 AI 行为。

## 技术难点总结

| 难点 | 说明 |
|------|------|
| 动画与物理混合移动 | Root Motion 与 CharacterController 的协调，索敌模式下切换为代码驱动移动 |
| 多状态战斗节奏控制 | Coroutine 驱动的前摇/判定/后摇状态机，连击输入缓冲队列 |
| AI 环绕移动算法 | 四元数旋转计算环绕轨迹 + NavMeshAgent.Move 实现非寻路移动 |
| 反击演出双端同步 | 玩家与敌人的 Animator 状态、位置、朝向需精确同步 |
| 动画控制器运行时替换 | 保持 Animator 状态平滑过渡的同时切换整套攻击动画 |

## 验证方式

- 在 Unity Editor 中 Play 模式测试战斗连击、反击、索敌锁定
- 测试敌人 AI 巡逻→发现→追击→攻击→后撤完整流程
- 装备不同武器验证动画覆盖切换
- 关闭游戏重新打开验证背包数据持久化
